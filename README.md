# learning-python

Мой путь в Python, данные и нейросети: заметки, упражнения, проекты 🐍

## 🎯 Цель

Освоить Python → анализ данных → нейросети и собрать портфолио на GitHub.

## 🗺 Дорожная карта

### Этап 1: Основы Python (1–2 месяца)
- [ ] Переменные, типы данных, ввод/вывод
- [ ] Условия и циклы
- [ ] Функции
- [ ] Списки, словари, кортежи
- [ ] Работа с файлами

📚 Ресурсы: Stepik «Программирование на Python», книга «Automate the Boring Stuff with Python»

### Этап 2: Работа с данными (1–2 месяца)
- [ ] numpy — массивы и вычисления
- [ ] pandas — таблицы и анализ
- [ ] matplotlib — графики
- [ ] Проект: разбор открытого датасета с kaggle.com

### Этап 3: Первые нейросети (2–3 месяца)
- [ ] scikit-learn — классическое машинное обучение
- [ ] PyTorch — основы
- [ ] Проект: распознавание рукописных цифр (MNIST)

### Этап 4: Портфолио и заработок
- [ ] 3–4 законченных проекта с красивыми README
- [ ] Kaggle-соревнования
- [ ] Стажировки и фриланс
